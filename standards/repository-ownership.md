# Repository ownership standard

| Area | Canonical owner | Consumer responsibility |
| --- | --- | --- |
| AI-agent governance, execution, testing, security and collaboration | `hb-AI-policy` | Link to the applicable policy; add only narrower local rules |
| Visual identity, tokens, official assets, reusable UI and Adigun BOT component standard | `hb-design-system` | Consume documented standards; do not duplicate or replace approved assets |
| Public corporate representation | `HephzibahBehulahHQ.github.io` | Link to the public corporate site where appropriate |
| Division mission and domain guidance | Matching `hb-*` division repository | Apply only to that division's products |
| Application code, data, tests, deployments and product integrations | Matching product repository | Maintain the complete product lifecycle there |

Local instructions may be stricter for documented product, legal, security or safety reasons. They must not weaken this policy or misrepresent unverified capabilities.
